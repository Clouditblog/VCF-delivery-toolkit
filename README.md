# vcf-delivery-toolkit

Scripts and tools used when delivering VCF projects.

| Folder | What it does |
|---|---|
| `plan-to-tracker` | Word implementation plan in, Excel tracker out (PowerShell with cmd launchers, or Python) |
| `sos-report-to-excel` | VCF SoS health-check report in, colour-coded Excel out (PowerShell) |
| `weekly-time-tracker` | Weekly project hours sheet with 8h/day and 40h/week targets |
| `rvtools-upgrade-advisor` | RVTools exports in, VCF 9.1 / VVF 9.1 readiness report out (HTML and Excel, PowerShell) |
